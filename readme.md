# tgBotAI
My first project

Бот с интеграцией облачной модели ИИ (для экономии вычислительных ресурсов)
и локальным развертыванием модели embedding.
Имеет гибкую настройку, добавление своих примеров для ответа на 
основе БД векторов.
Возможно настроить под любую задачу, добавить мультимодальную модель.
В качестве основной БД используется SQlite.
На основе промта и предоставленных примеров формирует ответ на любой вопрос
(для более точных ответов, необходим большой датасет качественных вопрос-ответ
, 100 шт и более).


1. Точка входа в программу - bot.py
2. Развернуть можно на любом сервере с конфигурацией офисного ПК
3. Логика разбита на модули

Инструкция по запуску:

Для запуска необходимо установить Ollama с официального сайта.
После открыть командную строку и выполнить команду:
1. ollama pull nomic-embed-text:v1.5, установится модель 
для работы с embedding
2. Зарегистрировать ключ API на сайте Ollama
3. После создать файл .env в главной директории проекта и на основе файла
.env.example  - подставить значения в константы файла
4. После получить уникальный токен бота у @BotFather в мессенджере Telegram.
токен необходимо подставить в значения констант в файл .env
